# Link Shortener
Консольное приложение на Java для сокращения ссылок и управления ими. Позволяет ограничивать количество переходов и автоматически удаляет ссылки по истечении срока действия.
Возможности
- Создание уникальных коротких ссылок.
- Открытие исходного URL в браузере.
- Настройка и изменение лимита переходов.
- Автоматическое удаление просроченных ссылок.
- Идентификация пользователей по UUID без регистрации.
- Редактирование и удаление ссылок только их владельцем.
- Уведомления об истечении срока действия или исчерпании лимита.
- Сохранение данных между запусками приложения.
Запуск
Для работы необходим JDK 17 или новее. Дополнительные библиотеки не требуются.

Скачайте или клонируйте репозиторий и выполните команды из корневой папки проекта.

Windows (PowerShell):
powershell -ExecutionPolicy Bypass -File scripts/build.ps1
java -jar out/link-shortener.jar
Linux / macOS:
bash scripts/build.sh
java -jar out/link-shortener.jar
Также приложение можно запустить в IntelliJ IDEA: откройте проект, выберите JDK 17, отметьте src/main/java как Sources Root и запустите класс Main. Рабочая директория — корневая папка проекта.
Пример использования
Создайте ссылку с лимитом в два перехода:
create https://example.org 2
Приложение выдаст короткую ссылку, например https://short.local/aB3x7Qz. При первом создании ссылки также генерируется UUID пользователя. Его нужно сохранить, чтобы в дальнейшем управлять своими ссылками.

Для перехода введите полученный код или короткий адрес в консоль:
open aB3x7Qz
После двух переходов ссылка будет заблокирована. Владелец сможет увеличить лимит, пока не истёк срок действия ссылки. По умолчанию он составляет 24 часа.

Короткие адреса работают внутри приложения, а не в адресной строке браузера. Для открытия исходного URL необходима графическая среда с браузером по умолчанию.
Команды
Команда	Описание
help	Список команд
create URL [лимит]	Создать короткую ссылку
open КОД	Открыть ссылку в браузере
list	Показать свои ссылки
edit-limit КОД ЛИМИТ	Изменить общий лимит переходов
edit-url КОД URL	Изменить исходный URL
delete КОД	Удалить ссылку
whoami	Показать текущий UUID
new или logout	Завершить текущую сессию
login UUID	Вернуться к своим ссылкам
notifications	Показать новые уведомления
exit	Выйти из приложения


Квадратные скобки обозначают необязательный параметр. Вместо КОД и UUID используйте значения, полученные от приложения. Не передавайте свой UUID другим пользователям.
Настройки
Параметры приложения находятся в файле config.properties.
Параметр	По умолчанию	Описание
ttl.seconds	86400	Время жизни новой ссылки в секундах
limit.default	10	Лимит переходов по умолчанию
limit.max	1000000	Максимальный лимит
short.prefix	https://short.local/	Префикс короткого адреса
code.length	7	Длина короткого кода
cleanup.millis	1000	Интервал очистки в миллисекундах
data.file	data/state.properties	Файл хранения данных


Настройки читаются при запуске. Изменение TTL влияет только на новые ссылки. Данные хранятся локально, в незашифрованном файле; приложение рассчитано на один процесс с переключением пользователей.
Структура проекта
- core — модели, сокращение ссылок, проверка прав, лимитов и срока действия.
- infra — генерация кодов, хранение данных, конфигурация и открытие браузера.
- ui — консольный интерфейс и обработка команд.
- Main.java — запуск приложения и планировщика очистки.
- src/test/java — автоматические тесты.
Тестирование
Скрипты сборки автоматически запускают 23 теста: 19 модульных и 4 интеграционных. Проверяются уникальность ссылок, лимиты, TTL, права владельцев, уведомления, сохранение данных и работа консольных команд.

Для запуска тестов используйте команды сборки из раздела «Запуск». В автоматических тестах браузер заменён тестовой реализацией; фактическое открытие браузера можно проверить вручную командой open.

Для быстрой проверки TTL установите ttl.seconds=10 в конфигурации, перезапустите приложение и создайте новую ссылку. Через 10 секунд она станет недоступной, а владелец получит уведомление.

GitHub Actions автоматически запускает сборку, тесты и проверку предупреждений компилятора при push и pull request.
